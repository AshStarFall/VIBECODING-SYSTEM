# Resource Evaluation Card

Copy this template for a resource whose choice materially affects a project. A short catalog entry does not require a full card.

```text
NAME:
URL / canonical upstream:
TYPE: library | service | documentation | skill | MCP | template | tool
CATEGORY:
USE WHEN:
DO NOT USE WHEN:
STACK / platform compatibility:
WHAT IT SOLVES:
WHY IT MATTERS:
ALTERNATIVES:
SECURITY / permissions / data handling:
LICENSE:
MAINTENANCE / release activity:
SETUP / operational burden:
TOKEN / context cost: low | medium | high, with reason
PRICING / limits: link to official current terms
NOTES / verified claims:
LAST VERIFIED: YYYY-MM-DD
```

Mark unknown facts `not checked`; do not fill them with guesses. Prefer official pages for license, pricing, version support, and data terms.
