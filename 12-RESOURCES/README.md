# Curated Resource Index

This is a discovery index, not a dependency list. Repeated entries from the supplied notes have been consolidated by capability. A repository link does not mean the project is maintained, secure, compatible, or recommended for every app.

## Selection standard

Prefer official documentation for facts and a small set of complementary tools. Before adoption verify the current upstream, supported versions, license, maintenance, security posture, permissions/data terms, pricing, and setup burden. Prefer a maintained alternative if a candidate is archived or superseded. Use [`RESOURCE-CARD.md`](RESOURCE-CARD.md) to document deeper evaluations.

## Curation notes

- Consolidated repeated entries: Spec Kit, FastAPI full-stack template, Supabase, Playwright, security tools, OWASP, testing, SEO, and design resources.
- Not every social screenshot could be reliably attributed or transcribed. Image files were intentionally not copied; use source links and primary documentation instead.
- Pricing and platform policies (including hosting free tiers) are volatile. Verify official terms immediately before adoption.
- Database MCP servers and tutorials can become archived; check the current upstream status before configuring one.
